## 你会在这里看到什么

- **学习笔记**：我在学习新技术过程中的记录，包括概念理解、实操步骤、踩坑经验
- **技术想法**：对技术趋势的思考、架构设计讨论、项目复盘

## 如何使用这个博客

如果你也想用 Hexo + GitHub Pages 搭建自己的博客，整个流程其实很简单：

1. 在本地写 Markdown 文件
2. `git push` 到 GitHub 仓库
3. GitHub Actions 自动构建并发布

就这样，不需要服务器，不需要数据库，免费托管。
